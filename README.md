

# 🌤️ Weather App

A real-time weather application that provides current weather conditions for any city worldwide. Built with pure HTML, CSS, and JavaScript.

## 🌐 Live Demo

**Click here to see the live app:** 👉 https://zaheenahamd78.github.io/weather--app/

## 📱 Features

- 🔍 **Search any city** - Get weather for any city in the world
- 🌡️ **Temperature** - Shows current temperature in Celsius
- 💧 **Humidity** - Real-time humidity percentage
- 💨 **Wind Speed** - Current wind speed in km/h
- 🎨 **Dynamic Icons** - Weather icons change based on conditions:
  - ☁️ Clouds
  - ☀️ Clear
  - 🌧️ Rain
  - 🌦️ Drizzle
  - 🌫️ Mist
- 📱 **Fully Responsive** - Works perfectly on mobile, tablet, and desktop

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure of the app |
| CSS3 | Styling and responsive design |
| JavaScript | Functionality and API calls |
| OpenWeatherMap API | Real-time weather data |

## 🚀 How to Use

1. Open the live link: https://zaheenahamd78.github.io/weather--app/
2. Type any city name in the search box
3. Click the search button (🔍)
4. View the current weather conditions
